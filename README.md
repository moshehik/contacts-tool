# יצירת אנשי קשר מקובץ Excel

כלי סטטי (HTML+JS בלבד, ללא שרת/בקאנד) שממיר קובץ Excel לקובץ אנשי קשר מוכן לייבוא לפלאפון.
תומך בשני סוגי רשימות, והקידומת לשם ניתנת לבחירה בעמוד:

- **תלמידים (3 טלפונים לשורה)** — כל מספר הופך לאיש קשר נפרד: `<קידומת> <משפחה> בית/אבא/אמא`.
- **רשימת אנשי קשר (טלפון אחד לשורה)** — כל שורה הופכת לאיש קשר אחד: `<קידומת> <משפחה> <שם פרטי>`.

כל העיבוד קורה בצד הלקוח (בדפדפן) — אף קובץ לא נשלח לשום שרת.

## אתר חי

https://moshehik.github.io/contacts-tool/

## שימוש מקומי

לחיצה כפולה על `open.bat` פותחת את `index.html` בדפדפן ברירת המחדל (עובד גם בלי אינטרנט).

## פורמטים נתמכים

- **Google CSV** — לייבוא ב-contacts.google.com, מתאים למכשירים המסתנכרנים עם חשבון Google
  (כולל קיוליקס QLYX Q7 ופלאפונים כשרים מבוססי אנדרואיד).
- **vCard (VCF)** — פורמט אוניברסלי, לשחזור מכרטיס זיכרון או שליחה ישירה בוואטסאפ/מייל.
  מתאים לרוב הפלאפונים הכשרים ולאייפון.

## התאמה לסוגי מכשירים

בשלב 2 בוחרים את דגם היעד והכלי ממליץ על הפורמט, ובשלב 4 יש הוראות יבוא לכל מכשיר:

- **קיוליקס Q7 / אנדרואיד** — Google CSV דרך contacts.google.com, המכשיר מסתנכרן לבד.
- **קיוליקס Q8 כשר (כרטיס בלבד, עד 3000 אנשי קשר)** — VCF 2.1 לתיקיית `vCard`
  בכרטיס, וייבוא דרך תפריט אנשי הקשר (פתיחה ישירה דרך מנהל הקבצים מייבאת רק איש קשר אחד!).
- **פלאפון כשר ישן** — VCF לשחזור מכרטיס זיכרון, עם אפשרות המרה דרך FK TOOL לדגם מדויק.
- **אייפון** — VCF במייל/וואטסאפ ו"הוסף את כל אנשי הקשר".

## ניקוי VCF מייצוא Q7 (שלב 5)
הייצוא מה-Q7 מוסיף לשמות סיומות מונה (`_1`, `_1_1`, `_2`...). שלב 5 מקבל קובץ VCF,
מסיר את הסיומות מהשדות FN/N (המספרים והפורמט נשמרים) ומחזיר VCF 2.1 נקי שמוכן לייבוא ל-Q8.
מומלץ למחוק את אנשי הקשר הישנים מהמכשיר לפני הייבוא המתוקן כדי למנוע כפילויות.

## פרוטוקול העברה Q7 ←→ Q8

התהליך המלא המוכח מהשטח (ייצוא, הגדרות Q8, ניקוי, כרטיס, יבוא, אימות
וטבלת תקלות) מתועד ב-[PROTOCOL.md](PROTOCOL.md).

בעמוד עצמו יש הוראות שלב-אחר-שלב לפי סוג המכשיר (קיוליקס/אנדרואיד, פלאפון כשר ישן, אייפון).

## פורמט קובץ הקלט (Excel)

**תלמידים (3 טלפונים):** מספר (אופציונלי), משפחה, שם פרטי, תאריך לידה, כתובת, טלפון, טלפון, טלפון
(3 עמודות טלפון: בית, אבא, אמא - לפי סדר זה). ערך `0` בעמודת טלפון מדלג על אותו איש קשר.

**רשימת אנשי קשר (טלפון אחד):** תואר (מתעלמים ממנו), משפחה, שם פרטי, כתובת (מתעלמים ממנה), טלפון.
שורה בלי טלפון מדולגת.

זיהוי העמודות מבוסס על מילות המפתח בשורת הכותרות ("משפחה", "פרטי", "טלפ") ולא על מיקום קבוע,
כך שסדר עמודות שונה בקובץ בדרך כלל עדיין יעבוד.
