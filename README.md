# יצירת אנשי קשר לגוגל מקובץ Excel

כלי סטטי (HTML+JS בלבד, ללא שרת/בקאנד) שממיר קובץ Excel של תלמידים לקובץ CSV
בפורמט הרשמי של Google Contacts (Import). לכל מספר טלפון בשורה נוצר איש קשר
נפרד בשם `פז <משפחה> בית/אבא/אמא`.

כל העיבוד קורה בצד הלקוח (בדפדפן) — אף קובץ לא נשלח לשום שרת.

## שימוש מקומי

לחיצה כפולה על `open.bat` פותחת את `index.html` בדפדפן ברירת המחדל.

## שימוש דרך GitHub Pages

לאחר הפעלת GitHub Pages על הריפו הזה (Settings → Pages → Branch: main, folder: /root),
העמוד יהיה זמין בקישור כמו:

```
https://<username>.github.io/contacts-tool/
```

## פורמט קובץ הקלט (Excel)

עמודות: מספר (אופציונלי), משפחה, שם פרטי, תאריך לידה, כתובת, טלפון, טלפון, טלפון
(3 עמודות טלפון: בית, אבא, אמא - לפי סדר זה). ערך `0` בעמודת טלפון מדלג על אותו איש קשר.
